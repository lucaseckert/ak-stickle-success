## README: tidy-data

This folder contains processed data files, described below:

- `ancestry-sims/`: `RDS` files from the results of ancestry simulations

- `constants.R`:  useful constants, factors, and functions, reused in several scripts

- `env-data.csv`: cleaned environmental data

- `env-dists-new.csv`: computed envionmental distances between lakes

- `final-ancestry.csv`: final inferred proportional ancestry of every fish

- `g-ancestry.csv`: subset of ancestry for just G Lake

- `g-props.RDS`: G stocking proportions

- `mean-source-effects.csv`: mean effect of each source population from the success GLMMs

- `other-data/`: miscellaneous auxiliary data files, including stocking data, genetic diversity, morphology, etc.

- `source-success-counts.csv`: processed source success data ready for analysis

- `success-data.csv`: proccessed success data ready for visualiztion
