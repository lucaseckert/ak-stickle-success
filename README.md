## Alaska stickleback project: source population success

This repository contains data and scripts for analyzing source population success in the [Alaska Stickleback Project](https://alaskastickleback.com/). All questions can be directed to Lucas Eckert ([lucas.eckert\@mail.mcgill.ca](mailto:lucas.eckert@mail.mcgill.ca){.email}). This analysis corresponds to the following [preprint](https://www.biorxiv.org/content/10.64898/2026.02.04.699496v1) and is being made available for consideration in review.

The repository is organized into the following directories:

-   `00_raw-data/`: Contains raw genotyping and environmental data.

-   `01_scripts/`: Contains all scripts for analysis and visualization.

-   `02_tidy-data/`: Contains processed data, used for further analysis.

-   `03_figures/`: Contains figures, but is currently ignored by git.

Please see the `README` file within each folder for details.
