## README: scripts

This folder contains all scripts for analysis and visualization, each of which are described below:

-   `ancestry-inference.R`: This script is used to infer proportional ancestry of each fish from the raw genotyping data.

-   `ancestry-sims.R`: This script uses simulations to assess the accuracy of the ancestry inference methods.

-   `drift-sims.R`: This script uses simulations to assess if the changes in ancestry proportions are greater than those expected by drift alone.

-   `env-correlations.R`: This script is used to assess correlations between environmental variables and stickleback morphology.

-   `env-data-cleaning.R`: This script is used to compile and clean the environmental data, for further analysis.

-   `env-distance.R`: This script is used to calculate environmental distances between lakes, for further analysis.

-   `mortalities.R`: This script explores data from mortalities during translocation and calculates the actual stocking numbers.

-   `source-success.R`: This script uses the ancestry inferences to quantify and visualize the success of each source population in each lake.

-   `success-models.R`: This script uses GLMMs to model source population success as a function of source population identity and environmental distance.

-   `trait-models.R`: This script assesses the relationship between population-level characteristics and source population success.
